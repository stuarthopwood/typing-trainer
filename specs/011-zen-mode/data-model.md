# Data Model: Zen Mode

## Entities

### TopicPrompt

Generated by `/api/zen-topic`. Displayed above the typing area.

| Field | Type | Description |
|-------|------|-------------|
| text | string | The topic prompt (5-10 words, open-ended question) |
| generatedAt | string (ISO 8601) | When the topic was generated |

### ZenSessionState (client-side, ephemeral)

Live state during a zen typing session. Not persisted — used only during the session.

| Field | Type | Description |
|-------|------|-------------|
| topic | string | The current topic prompt |
| text | string | The full typed text so far |
| startTime | number | performance.now() at first keystroke |
| wordCount | number | Current word count (non-whitespace sequences) |
| keyStrokes | KeyStroke[] | Full keystroke array (expected=actual, correct=true) |
| uncheckedWords | { word: string; startIndex: number; endIndex: number }[] | Words not yet spell-checked |
| spellResults | Map<number, SpellCheckResult> | Results keyed by word start index |
| isComplete | boolean | Whether Done has been pressed |

### SpellCheckResult

Returned by `/api/zen-spellcheck` for each word in a batch.

| Field | Type | Description |
|-------|------|-------------|
| word | string | The original word that was checked |
| correct | boolean | Whether the word is correctly spelled |
| suggestion | string? | Suggested correction (if misspelled) |
| index | number | Position in the batch (maps back to word position in text) |

### ZenSessionSummary (recorded on completion)

Extends `EnrichedSessionSummary` with zen-specific fields:

| Field | Type | Description |
|-------|------|-------------|
| modeDetails.type | "zen" | Mode identifier |
| modeDetails.topic | string | The topic prompt that was used |
| wpm | number | Words per minute (total chars / 5 / duration in minutes) |
| accuracy | number | Spelling accuracy (correctly spelled / total checked × 100) |
| charsTyped | number | Total characters typed |
| duration | number | Session duration in milliseconds |
| wordCount | number | Total words typed |
| misspelledWords | string[] | List of misspelled words (for review) |

## State Transitions

### Zen Session Lifecycle

```
Idle (no topic)
  → Topic Generated (topic displayed, typing area ready)
  → Typing (first keystroke starts the timer)
  → Done Pressed (final spell-check runs)
  → Session Recorded (summary shown, data persisted)

Cancel path:
  Typing → New Topic Pressed → Idle (no data recorded)
```

### Word Spell-Check Lifecycle

```
Unchecked (word typed but not yet sent for checking)
  → Pending (batch sent to API, awaiting response)
  → Checked: Correct (green/neutral state)
  → Checked: Misspelled (red underline)
  → Timeout: Unchecked (API didn't respond in 3s, retried at session end)
```

## Validation Rules

- Topic prompt: must be non-empty, 5-50 characters.
- Word count: only sequences of non-whitespace characters count. Punctuation attached to words counts as part of the word.
- Minimum 20 words to enable Done button.
- Spell-check batch: 1-5 words + up to 6 words of surrounding context.
- Session duration: must be > 0ms (at least one keystroke occurred).
